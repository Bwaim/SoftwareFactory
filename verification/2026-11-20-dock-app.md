# Dock app manual tests

The CAPTN Dashboard app is a GUI. These tests need a person at the Mac. Build the app first with `factory app install` (or `./install.sh`).

Build check (automated, no launch): `FACTORY_DASHBOARD_APP=<tmp>/CAPTN Dashboard.app FACTORY_LSREGISTER= ./bin/factory app install` printed `Dashboard app: <tmp>/CAPTN Dashboard.app` and `Drag it to the Dock to keep it there.`. The bundle is signed ad hoc, with bundle id `com.captn.factory.dashboard`, and `CAPTNUv` and `CAPTNFactory` in `Info.plist`.
